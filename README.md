# News Aggregator

CLI-агрегатор новостей из RSS-лент. Скачивает статьи с нескольких источников, сохраняет в SQLite, позволяет искать по заголовкам, фильтровать по источнику и периоду.

## Что умеет

- Собирает RSS с 5 источников: Habr, ТАСС, РБК, Lenta, РИА
- Дедупликация по URL — одна и та же статья не сохранится дважды
- Поиск по заголовкам с фильтрами (источник, N последних дней)
- Список источников с количеством статей
- Статистика базы

## Стек

- Python 3.10+
- `requests` — HTTP
- `feedparser` — парсинг RSS
- `sqlite3` — база данных (встроен в Python)
